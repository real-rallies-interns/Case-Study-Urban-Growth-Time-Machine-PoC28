# Data Dictionary: Urban Growth Time Machine (Synthetic)

This document defines the entities and fields used in the synthetic urban growth dataset. All data generated by this package is synthetic and for demonstration purposes only.

## Entities

### 1. GrowthRegion (AOI)
Represents a specific geographic area under observation.

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `id` | String | Unique identifier for the region. | `REG-001` |
| `name` | String | Human-readable name of the region. | `Bangalore West Corridor` |
| `latitude` | Float | Center latitude coordinate. | `12.9716` |
| `longitude` | Float | Center longitude coordinate. | `77.5946` |
| `zoom` | Float | Recommended map zoom level. | `12.5` |
| `is_synthetic` | Boolean | Flag indicating the record is synthetic. | `true` |

### 2. GrowthMetric
Spatiotemporal metrics for a specific year in a region.

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `aoi_id` | String | Reference to the GrowthRegion. | `REG-001` |
| `year` | Integer | Observation year. | `2023` |
| `built_up_area_sqkm` | Float | Total physical area covered by buildings. | `150.25` |
| `population_density` | Float | People per square kilometer. | `12500.5` |
| `growth_velocity_pct` | Float | Percentage change from previous year. | `5.2` |
| `infrastructure_index` | Float | Score of physical infrastructure density (0.0 - 1.0). | `0.85` |
| `capital_investment_m_usd` | Float | Total investment in Millions USD. | `120.5` |
| `land_use_type` | String | Classification (URBAN, RURAL, INDUSTRIAL, etc.). | `URBAN` |
| `confidence_score` | Float | Spectral confidence in detection (0.0 - 1.0). | `0.92` |
| `is_synthetic` | Boolean | Flag indicating the record is synthetic. | `true` |

### 3. IntelligenceInsight
Summary insights and intelligence scores for a region.

| Field | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `aoi_id` | String | Reference to the GrowthRegion. | `REG-001` |
| `intelligence_score` | Float | Normalized score of urban stability (0.0 - 1.0). | `0.78` |
| `trend_anomaly` | String | Categorical trend state. | `ACCELERATING` |
| `insight_summary` | String | AI-generated summary of the growth pattern. | `Rapid expansion detected...` |
| `is_synthetic` | Boolean | Flag indicating the record is synthetic. | `true` |

## Edge Case Definitions

- **Missing Data**: Records with null values in non-essential fields to test frontend resilience.
- **Extreme Growth**: Velocity spikes (>50%) to test anomaly detection.
- **Negative Growth**: Abandonment scenarios (area/pop decrease).
- **Invalid Coordinates**: Latitude/Longitude outside standard ranges to test boundary checks.
